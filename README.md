# 300英雄 自动脚本

自动完成 **常驻活动 → 好运星盘 → 星屑占卜**：按数学最优策略把每天的占卜次数用完（平均约 178 星砂/局），完成后回到大厅。

## 使用方法（免安装）
1. 把压缩包 **全部解压** 到任意文件夹（路径可以有中文和空格，不要在压缩软件里直接双击运行）。
2. 启动 **300英雄**，登录后停在 **大厅主界面**。
3. 双击 **`300HeroAuto.exe`**，在「星屑占卜」页左下角点 **运行脚本**（左侧星盘会实时显示翻牌和选线）。

- 不需要安装 Python 或其他任何环境，所需运行库都在 `toolkit/` 里。
- 游戏窗口分辨率任意，脚本会自动识别缩放；运行期间脚本会把游戏窗口临时置顶，结束后恢复。
- 随时可点 **停止运行**，或按 **F12** 立即停止。关闭窗口也会先安全停止脚本。
- 顶栏右侧 **迷你模式** 按钮：窗口缩成贴在屏幕右侧、高 720 的窄条，只保留运行/停止按钮、星盘、运行状态和日志，不挡游戏；点窄条右上角的 ⤢ 还原。
- 网络差、点击常常没反应时，把“点击响应等待秒数”调大。

## 录制操作（给 agent 学习用）
左侧「操作录制」，点左下角 **开始录制**，再点一次（或按 **F10**）停止。只录游戏窗口内部，游戏最小化时自动暂停。
每次录制保存在 `recordings/<时间>/`：

| 文件 | 内容 |
|---|---|
| `steps.md` | **给 agent 读的步骤清单**：每次点击的时间、位置（窗口内比例坐标，与分辨率无关）、点击前/后截图 |
| `events.jsonl` | 所有事件（点击、按键、暂停/恢复、被遮挡），每行一个 JSON |
| `frames/` | `0001_before.jpg`（点击前一刻，红圈标出点击位置）/ `0001_after.jpg`（约 0.8 秒后） |
| `video.mp4` | 整段视频（点击处有红圈），用 Windows 媒体播放器 / VLC 观看 |
| `meta.json` | 时长、帧率、窗口大小、点击/按键次数 |

- 只记录点在游戏窗口里的点击，以及游戏在前台时的按键；脚本自动点击会标注“脚本”。
- 按键会被记录（包括聊天输入），不想记录可在录制页关掉“记录键盘按键”；分享录像前注意画面里的聊天和账号名。
- 游戏窗口被其他窗口挡住时，那段画面录到的是挡在前面的窗口，`events.jsonl` 会记一条 `occluded` 提醒。

## 出问题时
- 界面日志里会写明停止原因；异常时的游戏截图保存在 `stardust/captures/unexpected.png`。
- 界面服务日志：`log/gui.txt`；脚本日志：`stardust/stardust_log.txt`；历次运行记录：`history.json`（界面「运行记录」页）。
- 如果游戏以 **管理员身份** 运行，本程序也需要右键“以管理员身份运行”，否则 Windows 会拦截点击。

## 目录
| 路径 | 说明 |
|---|---|
| `300HeroAuto.exe` | 启动器（双击这个） |
| `gui.py` | 界面后端（Tornado JSON API：运行控制、日志、统计、配置） |
| `webui/` | 界面前端（HTML/CSS/JS，无外部依赖，离线可用） |
| `stardust/` | 星屑占卜 脚本（求解器、识别、导航） |
| `recorder/` | 操作录制（视频 + 点击/按键 + 前后截图） |
| `recordings/` | 录像输出目录（首次录制时创建） |
| `toolkit/python/` | 内嵌 Python 3.12 及依赖 |
| `toolkit/WebApp/` | 桌面窗口（Electron） |

开发者：`python build.py` 重新生成一键包 `dist/300HeroAutoScript.zip`。
