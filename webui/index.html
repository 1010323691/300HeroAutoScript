    玩法

    3×3 星盘随机放入 1–9，系统先翻开 1 格；玩家再翻开 3 格（共 4 格可见），最后选择一条线（3 行 / 3 列 / 2 条对角线），三个数之和换取星砂。

    奖励表 线和 → 星砂

    500 星砂100–150 星砂10–50 星砂

    最优策略

    脚本对所有可能的排列做精确期望值计算：每一步都选择期望星砂最高的格子或线路，平均约 178 星砂 / 局。奖励两头高、中间低，所以脚本会优先追求极端的和（6–7 或 23–24）。

    安全措施

    每次点击后都会确认界面发生了预期变化，网络卡顿时自动等待或重试；运行期间游戏窗口临时置顶，结束后恢复。

    保存位置

    每次录制保存在 recordings/<时间>/：

    steps.md给 agent 读的步骤清单：每次点击的时间、位置（窗口内比例坐标，与分辨率无关）、点击前/后截图
    events.jsonl全部事件：点击、按键、暂停/恢复、窗口被遮挡，每行一个 JSON
    frames/0001_before.jpg 点击前一刻（红圈为点击位置）/ 0001_after.jpg 点击约 0.8 秒后
    video.mp4整段视频（点击处有红圈），用 Windows 媒体播放器或 VLC 观看
    meta.json时长、帧率、窗口大小、点击/按键次数

    注意

    只记录点在游戏窗口里的点击和游戏在前台时的按键；自动脚本的点击会标注“脚本”。按键包括聊天输入，分享录像前请注意画面里的聊天和账号名。游戏窗口被其他窗口挡住时，录到的是挡在前面的窗口。
